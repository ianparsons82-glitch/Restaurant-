# Getting Your Template Into Google Sheets

Google Sheets is recommended for team collaboration because all managers can view and edit simultaneously, with real-time updates and automatic syncing across devices.

## 5-Minute Setup Guide

### Step 1: Download the Excel File
Choose your design aesthetic:
- **Warm & Inviting**: Download `Warm-&-Inviting/Restaurant-Ops-Template-Warm.xlsx`
  (Navy, coral, cream colors)
- **Modern Restaurant-Specific**: Download `Modern-Restaurant-Specific/Restaurant-Ops-Template-Modern.xlsx`
  (Dark green, charcoal, bronze colors)

### Step 2: Upload to Google Drive
1. Go to **Google Drive** (drive.google.com)
2. Click **"+ New"** button (top left)
3. Select **"File upload"**
4. Find and select the Excel file you downloaded
5. Wait for upload to complete

### Step 3: Convert to Google Sheets
1. Right-click the uploaded Excel file in Google Drive
2. Select **"Open with" → "Google Sheets"**
3. Google automatically converts it to a Sheet (takes 10-15 seconds)

### Step 4: Save as Your Own Copy
1. Once converted, click **File** (top menu)
2. Select **"Make a copy"**
3. Name it something like:
   - "Restaurant Operations - [Your Restaurant Name]"
   - "Manager Dashboard - May 2026"
4. Click **"Create copy"**

**WHY A COPY?** This keeps the original as a backup. Edit the copy—not the original file.

### Step 5: Share With Your Team
1. Click **Share** (top right of your new copy)
2. Choose team members to invite:
   - **Manager role**: Give "Editor" permission (can modify everything)
   - **Staff role**: Give "Viewer" permission (can see but not edit)
3. Click **Share** and send the link

### Step 6: Start Using It
- Managers open the link and start filling in data
- All changes sync instantly across devices
- No need to email files back and forth
- Everyone sees the latest version

## Quick Tips

### Offline Access
If your WiFi is unreliable:
1. Open your Google Sheet
2. Click **File → Make available offline**
3. Works offline and syncs when WiFi returns

### Print From Google Sheets
1. Click **File → Print** (or Ctrl+P)
2. Use the PDF preview to check layout
3. Click **Print** or **Save as PDF**

### Backup Your Data
Monthly backup recommended:
1. Open your Google Sheet
2. Click **File → Download**
3. Choose **Excel (.xlsx)** or **PDF**
4. Save to your computer as backup

### Sharing Passwords/Security
⚠️ **Important**: Google Sheets link gives editing access to anyone with the link (if not password protected).
- For sensitive data: Use Google's "Require sign-in" when sharing
- Consider: File → Share → Advanced → "Restricted" (only invited people can access)

## Troubleshooting

### Q: The colors look different in Google Sheets vs. Excel
**A:** Minor color variations are normal. Google Sheets renders some colors slightly differently. Functionality isn't affected. Print preview will show accurate colors.

### Q: Why are some formulas showing as text (not calculating)?
**A:** Usually because Excel used features Google Sheets doesn't support. All critical formulas (labor cost, reorder alerts) will work. If needed, email support@anthropic.com with the specific formula issue.

### Q: Can I edit the Google Sheet and keep the Excel as backup?
**A:** Yes! Edit the Google Sheet, and periodically:
1. Export as Excel: File → Download → Excel
2. Save to your computer as backup
3. This lets you have both versions

### Q: Multiple managers editing same sheet at once?
**A:** Perfect! Google Sheets handles this automatically:
- Managers can edit different sections simultaneously
- Changes merge together
- Last edit wins if two people change same cell

## Contact & Support

**Google Sheets not working?**
- Refresh the page (Ctrl+R)
- Clear browser cache
- Try a different browser

**Excel file won't open?**
- Make sure it's .xlsx format (not .xls or .pdf)
- Try opening in Google Sheets instead (easier)
- Update Excel to latest version

**PDF checklists look wrong when printed?**
- Ensure print setting: "Fit to 1 page width"
- Check margins aren't set to 0
- Print preview should show clean layout
