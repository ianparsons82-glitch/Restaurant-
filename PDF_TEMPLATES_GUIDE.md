## 🖨️ Printing & Formatting

### Page Size
- **Standard:** Letter (8.5" × 11")
- **Weekly Schedule:** Landscape orientation for better table visibility

### Print Quality
- **Resolution:** 72 DPI (screen viewing), scales to 300 DPI (printing)
- **Color Rendering:** Full color recommended for brand consistency
- **B&W Conversion:** All text readable in grayscale; signature colors convert to light gray

### Lamination Recommendations

**Materials:**
- 3-mil thermal laminating pouches (professional lamination)
- 5-mil for high-traffic areas (more durable)

**Process:**
1. Print at 100% scale (no shrinking)
2. Cut to size if needed
3. Laminate with 3-5 mil pouches
4. Use adhesive dry-erase or wet-erase pens for form filling

**Benefits:**
- Reusable (can be wiped clean)
- Water-resistant
- Durable for daily use in kitchen/FOH environments
- Professional appearance
- Cost-effective for multiple uses

## 🚀 Usage Recommendations

### Best Practices

**Daily Opening:**
1. Print a fresh copy each day (or use laminated/reusable version)
2. Manager completes before staff briefing
3. File completed copy for compliance records
4. Note any issues for follow-up

**Daily Closing:**
1. Complete throughout closing process
2. Each section lead initials their completed section
3. Manager final sign-off before leaving
4. Secure all documentation
5. Review issues in next manager meeting

**Weekly Planning:**
1. Create schedule Sunday evening/Monday morning
2. Calculate labor costs and compare to budget
3. Identify staffing gaps or overstaffing
4. Document planning notes for team communication

**Inventory Management:**
1. Conduct inventory at same time weekly
2. Mark items for reorder during audit
3. Contact suppliers with reorder list
4. Track delivery and verify received items
5. Update inventory system

**Manager Tasks:**
1. Complete "Today's Priorities" first thing morning
2. Check off daily recurring tasks throughout shift
3. Review weekly tasks and update completion dates
4. Use notes section for follow-up items
5. Review previous week's notes for continuity

## 📞 Support & Updates

### Troubleshooting

**PDFs won't open:**
- Ensure Adobe Reader or compatible PDF viewer installed
- Download latest version of PDF reader
- Try alternative viewer (Chrome, Firefox)

**Form fields not working:**
- Check PDF reader supports interactive forms
- Try Adobe Reader (best compatibility)
- Save PDF before filling forms

**Printing issues:**
- Print at 100% (no scaling)
- Ensure color printer selected
- Check margin settings (0.75" minimum)

- Ensure sufficient screen brightness
- Text fields may require tap to activate
